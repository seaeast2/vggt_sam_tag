Fit/evaluation reruns create new run IDs; pass their explicit returned IDs downstream. Exporters reject existing per-case pointmap directories. Source snapshots are evidence copies; restore them to their original source paths to reproduce their relative-path conventions. Cached VGGT predictions were reused; all this execution was CPU-only. No GPU inference/training was run.

Evaluation uses exact rectified KITTI depth and official Middlebury PFM conventions. ETH3D selected-view LK support was zero in both held-out scenes; no corrected depth or GT accuracy is reported for ETH3D, and its original distorted GT was not directly mapped to undistorted RGB.

The primary paired comparison is B3 versus B2. Mean metrics give each evaluated case equal weight; datasets remain separate. ID bootstrap intervals are descriptive because scene/sequence independence is not established. GT reference direction uncertainty uses spatial block bootstrap. Reports keep all regressions and non-supported cases. Do not use ground-truth-best per-case arm selection as deployed performance.
