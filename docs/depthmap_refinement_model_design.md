# P16 · VGGT-Ω 깊이맵의 선택적 잔차 보정

## 연구 질문

VGGT-Ω의 원본 깊이와 confidence, RGB, SAM 경계를 입력으로 받는 작은 U-Net을 학습한다. 저신뢰 픽셀에서 카메라 광선을 따라 깊이를 앞이나 뒤로 조정하고, 다중시점 RGB 정합이 센서 깊이 감독만 사용했을 때보다 도움이 되는지 비교한다. VGGT-Ω와 SAM은 고정한다. 이 문서는 구현 및 평가 설계다.

P13은 색과 깊이의 경계가 뚜렷한 일부 픽셀에서 개선됐지만, 조건을 완화해 추가한 픽셀에서는 MAE가 11.36→13.43cm로 늘었다. P14는 프레임의 최대 깊이로 옮긴 점이 많아서 각 카메라의 원거리 면에 띠가 생길 수 있다. P15는 일부 관측을 공통 평면에 정렬했지만 사용자의 육안 검토에서 바닥 점이 벽에 붙는 문제가 나타났다. 따라서 P16은 어느 표면에 속하는지 불확실할 때 수정량을 작게 유지하는 능력과, 경계에서 깊이를 올바른 쪽으로 이동시키는 능력을 함께 평가한다. [기존 실험 기록](experiments/planar_residual_depth/index.md)

## 최소 모델

| 구성 | 초기 설계 |
|---|---|
| 입력 | 정렬된 RGB 3채널, 원본 camera-Z 1채널, raw confidence 1채널, SAM 경계 거리 맵 1채널 |
| 정규화 | 클립의 유효 원본 깊이 중앙값으로 깊이를 정규화하고 모델 출력에서 복원한다. confidence는 학습 데이터에서 산출한 고정 분위수 범위로 정규화한다. SAM 경계 거리는 입력 해상도 기준 8픽셀에서 자른다. |
| 네트워크 | 3회 다운샘플링 U-Net. 채널 24→48→96→128, 3×3 Conv·GroupNorm·SiLU, skip 연결, bilinear 업샘플링. 384×288부터 시작한다. |
| 출력 | 수정 강도 g = sigmoid(a), 깊이 잔차 비율 r = 0.3 tanh(b). 최종 깊이 D_out = D_raw × (1 + g × r). |
| 보호 | 고신뢰 보호 조건을 통과한 픽셀은 g를 0으로 설정한다. 첫 시도는 학습 데이터의 raw confidence 상위 30%에 대응하는 임계값을 사용한다. 시각화 색상은 임계값 산정에 사용하지 않는다. |
| 저장 | 원본 깊이, 잔차 D_out − D_raw, 적용 강도 g, 적용 마스크, RGB·SAM·카메라 출처를 저장한다. PLY는 같은 K와 pose로 복원한다. |

SAM의 마스크 번호는 입력으로 쓰지 않는다. 경계가 겹치면 마스크들의 내부 윤곽을 합쳐 거리 맵을 만든다. 모델은 색·깊이·confidence를 함께 보고 SAM 경계가 실제 깊이 단차인지 판단한다. ±30%는 초기 설계값이다. 센서 기준 오차 중 이 범위를 넘는 비율도 기록해, 큰 오류를 수정할 수 없는 경우와 모델이 잘못 배운 경우를 구분한다.

## 다중시점 학습

기준 영상 i의 픽셀 u를 보정된 camera-Z로 역투영한다. X_i = D_out(u) K_i⁻¹ [u, 1]ᵀ. 상대 자세 T_{j←i}로 이웃 영상 j의 카메라 좌표로 보낸 뒤 K_j로 투영한다. 그 좌표의 RGB를 bilinear sampling으로 읽어 기준 RGB와 비교한다. 평면과 비평면 모두 같은 방식으로 처리할 수 있다.

- 기준 프레임당 이웃 최대 2장을 사용한다. 시간 간격 외에 공통 가시 영역과 시차를 확인한다.
- 이미지 밖·카메라 뒤·가림·동적 영역을 제외한다. 가림은 소스 깊이와 투영 깊이의 일치 여부로 근사한다. 학습용 유효 마스크를 구성할 때 예측 보정값에 따라 임의로 표본 수가 줄지 않도록 원본 추론으로 정한 가시성 마스크를 고정하고, 보정 후 가시율도 따로 기록한다.
- 작은 RGB 밝기 차이를 허용하도록 L1과 SSIM을 섞고, 이웃별 손실 중 유효한 최솟값을 취한다. 두 이웃이 모두 무효면 해당 픽셀의 RGB 손실을 생략한다.
- 제공 카메라 자세 조건과 VGGT-Ω 추정 자세 조건을 따로 평가한다. 제공 자세의 이동량은 미터 단위이고 VGGT-Ω 깊이는 모델 스케일이므로 재투영 전에 단위를 맞춘다. 제공 자세 통제에서는 학습 중 유효 센서 깊이로 고정된 클립별 스케일을 구해 사용한다. 테스트에서 제공 자세와 센서 스케일을 쓰는 경우 별도 통제 결과로 표시한다. RGB 조건에서는 모델 깊이와 같은 스케일의 모델 자세를 사용한다.

초기 목적함수는 **유효 센서 깊이의 강건 손실 + λ_RGB × 유효 다중시점 RGB 손실 + λ_keep × 잔차 크기**다. λ_RGB=0을 기준으로 두고 양수 값은 검증 장면에서 정한다. 센서 깊이를 모델 스케일로 비교할 때 클립당 스케일 하나를 원본 출력에서 결정하고 모든 보정 방법에 동일하게 사용한다. 테스트에서 스케일 정렬이 필요하면 사전에 분리한 센서 보정 픽셀에만 적용하고 나머지 픽셀을 평가한다. 추론 모델 입력에는 센서 깊이를 제공하지 않는다.

## 실행 순서와 판정

| 단계 | 모델·조건 | 확인할 것 |
|---|---|---|
| P16a | VGGT-Ω 원본, 기존 P13 규칙, RGB+깊이 U-Net | 작은 모델이 원본과 규칙 대조군을 개선하는지 확인 |
| P16b | 같은 U-Net에 confidence, 다음으로 SAM 경계 추가 | 각 입력이 저신뢰 경계 보정 및 고신뢰 보존에 기여하는지 확인 |
| P16c | P16b에 다중시점 RGB 손실 추가 | 같은 모델에서 RGB 손실 유무를 비교. 제공 자세 통제와 모델 자세 조건을 분리 |
| P16d | 선택 실험. 원본 깊이 주변의 9개 깊이 후보에서 정합 비용을 구해 입력에 추가 | 추론 시점에서도 이웃 관측을 사용하는 모델이 P16c보다 개선되는지 비교 |

TUM 2초 간격 16장은 시각 점검과 파이프라인 확인에 쓴다. 학습과 성능 평가는 별도 장면에서 진행하고 인접 프레임이나 같은 물리 공간이 분할을 건너지 않도록 한다. 입력을 캐시해 8GB GPU에선 작은 배치와 혼합 정밀도부터 측정한다. 실제 VRAM, 가능한 배치 크기, 처리 시간은 구현 후 기록한다.

평가는 같은 GT 유효 픽셀에서 **전체·저신뢰·고신뢰 깊이 MAE와 AbsRel**을 비교한다. GT 깊이 단차 주변은 별도로 평가하고, 바닥이 벽에 붙는 현상은 독립적으로 검토한 바닥–벽 경계에서 어느 쪽의 오차가 늘었는지 확인한다. SAM 경계 전체를 GT 경계로 취급하지 않는다. 다중시점 정합은 학습 손실에 쓰지 않은 평가 프레임 쌍에서 RGB 재투영 오차와 유효 픽셀 비율을 함께 보고한다. 점군에서는 개별 프레임의 깊이 오차와 프레임 간 정합 오류를 분리해서 해석한다.

P16의 핵심 비교는 **같은 네트워크에서 다중시점 손실을 추가했을 때 저신뢰 경계의 GT 오차가 줄어드는가**다. 재투영 오차가 감소하더라도 GT 깊이 오차가 늘면 깊이 개선으로 판정하지 않는다. 보정 전후 동일한 픽셀, 적용 범위, 장면별 결과를 함께 남긴다.

## 구현 위치

모델, 캐시 형식, 실행 명령은 [P16 구현 안내](../experiments/planar_residual_depth/P16/README.md)에 있다. 합성 장면과 기존 TUM 캐시로 실행 경로를 확인했다. 실제 학습 장면을 사용한 성능 비교는 별도의 실험으로 진행한다.
