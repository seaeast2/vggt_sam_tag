# KITTI 000006 / K03 검토 대기

사전 평가 ID 순서대로 000006을 선택했다. RGB만 보고 source/target 도로 평면 후보를 지정했고 GT와 raw depth를 읽지 않았다. 기존 사용자 결정인 “후보 표시 후 내가 검토”에 따라 실제 보정 전 두 다각형 확인을 요청했다. 이전 K02 승인을 재사용하지 않는다.

후보: `results/planar_residual_depth/P3input-kitti-000006-20261117-001/RGB_plane_review.png`.

보정 설정은 P2/P3 000005와 동일하게 유지한다. 새 case의 명시적 승인 기록·case/image hash가 있어야 관측 추출·보정을 실행할 수 있도록 CLI를 일반화했고 구문 검사를 완료했다. 실제 000006 보정·GT 평가는 아직 미실행이다.

## 후속 완료 기록

사용자가 “응 도로 평면 안에 잘 들어와.”로 두 영역을 승인했다. 입력 run에 승인 원문과 case/image SHA256을 저장했다. 관측 FIT122·보류58개로 기존 지원 기준을 통과했고, 보정과 별도 GT 평가를 완료했다. 위의 대기 상태는 승인 전 기록이다. [최종 보고서](../kitti-000006-P3e-20261117-001/report.md).
