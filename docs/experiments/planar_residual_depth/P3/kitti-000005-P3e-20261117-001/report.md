# P3: KITTI 000005 도로 평면 고정 설정 평가

사전에 정한 평가 ID 000005를 순서대로 선택했다. RGB에서 지정한 K02 좌·우 도로 다각형에 대해 사용자가 "두 영역 모두 적절함"으로 확인했다. GT와 raw depth를 보지 않고 영역을 지정했다. P2의 매칭·지원 기준·스케일 정책·평면 적합·보정 solver를 유지했고 이 장면의 결과로 재조정하지 않았다.

B0: 원본×공통scale. B1: raw source로 적합한 평면 투영. B2: B1 방향 고정, 거리만 보정. B3: 방향·거리 공동 보정. 모든 군의 마스크·카메라·scale과 GT 평가 픽셀을 동일하게 유지했다. raw와 잔차를 별도 저장했으며 비대상 픽셀은 변경하지 않았다.

공통 평가 픽셀 7255개. GT는 KITTI disp_occ_0의 왼쪽 기준시각 disparity다. calib의 Z방향 baseline까지 포함한 정확한 rectified 역산 Z=fx*(Bx-rx*Bz)/d+Bz를 적용했다. 원본 GT를 최근접으로 처리 격자에 대응시키며 보간·결측 채움은 하지 않았다. 이전 P2e의 baseline norm 근사를 여기서는 사용하지 않는다. 이 변환 변경은 최적화에 영향을 주지 않는다. 오른쪽 GT 정확도는 평가하지 않았다.

GT는 보정 완료 후 별도 프로세스에서만 읽었다. FIT 출력의 평가 전후 hash 불변, 양의 깊이·Jacobian 수치 대조·rank·잔차 복원·비대상 불변 검사를 통과했다. solver.py는 P2 실행 스냅샷과 SHA256이 동일하다. 보류/GT로 평면을 재선택하지 않았다.

평가 ID로의 확장 사례 1개이며, 새로운 독립 공간이나 전체 KITTI/SLAM 정확도 검증은 아니다. ID 000000과 000005가 동일 촬영 구간에 속하는지는 검증하지 않았고 이미지에 유사한 거리·차량이 보인다. 영역은 수동 승인 평면이고 픽셀·LK 패치 사이에는 상관이 있다. 제공 카메라 보정을 사용하므로 RGB만으로 카메라 자세까지 추정하는 실험과 구별한다.

FIT: `results/planar_residual_depth/P3-kitti-000005-20261117-001/`. 평가·그림·PLY: `results/planar_residual_depth/P3e-kitti-000005-20261117-001/`.

이번 사례에서는 B2가 B0 대비 MAE를 약82.71%, B3가 약77.28% 줄였다. B3는 보류 재투영 오차가 B2보다 작지만 GT 깊이 오차는 약4.54cm 크고 법선 오차도 증가했다. 앞선 K01과 같은 순위가 나타났으나 원인이나 전체 데이터셋의 우월성을 확정하지 않는다. 고정 평가의 첫 사례만 완료했으며 나머지 평가 샘플은 미실행이다.
