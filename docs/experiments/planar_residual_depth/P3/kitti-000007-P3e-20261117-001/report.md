# P3: KITTI 000007 도로 평면 고정 설정 평가

사전에 정한 평가 ID 000007를 순서대로 선택했다. RGB에서 지정한 K04 좌·우 도로 다각형에 대해 사용자가 승인했다(원문: 두 영역 모두 적절함). GT와 raw depth를 보지 않고 영역을 지정했다. P2의 매칭·지원 기준·스케일 정책·평면 적합·보정 solver를 유지했고 이 장면의 결과로 재조정하지 않았다.

FIT 36개 / 보류 14개. FIT hull 비율 0.253, 중앙 시차 2.554°. FIT SIFT 501개로 공통 scale 18.044308073586. 보류 3px 이내 scale-FIT 제외 1개.

B0: 원본×공통scale. B1: raw source로 적합한 평면 투영. B2: B1 방향 고정, 거리만 보정. B3: 방향·거리 공동 보정. 모든 군의 마스크·카메라·scale과 GT 평가 픽셀을 동일하게 유지했다. raw와 잔차를 별도 저장했으며 비대상 픽셀은 변경하지 않았다.

공통 평가 픽셀 5793개. GT는 KITTI disp_occ_0의 왼쪽 기준시각 disparity다. calib의 Z방향 baseline까지 포함한 정확한 rectified 역산 Z=fx*(Bx-rx*Bz)/d+Bz를 적용했다. 원본 GT를 최근접으로 처리 격자에 대응시키며 보간·결측 채움은 하지 않았다. 이전 P2e의 baseline norm 근사를 여기서는 사용하지 않는다. 이 변환 변경은 최적화에 영향을 주지 않는다. 오른쪽 GT 정확도는 평가하지 않았다.

GT는 보정 완료 후 별도 프로세스에서만 읽었다. FIT 출력의 평가 전후 hash 불변, 양의 깊이·Jacobian 수치 대조·rank·잔차 복원·비대상 불변 검사를 통과했다. solver.py는 P2 실행 스냅샷과 SHA256이 동일하다. 보류/GT로 평면을 재선택하지 않았다.

평가 ID로의 확장 사례 1개이며, 새로운 독립 공간이나 전체 KITTI/SLAM 정확도 검증은 아니다. 개발 ID와 촬영 구간·실제 공간이 독립인지 검증하지 않았다. 영역은 수동 승인 평면이고 픽셀·LK 패치 사이에는 상관이 있다. 제공 카메라 보정을 사용하므로 RGB만으로 카메라 자세까지 추정하는 실험과 구별한다.

FIT: `results/planar_residual_depth/P3-kitti-000007-20261117-001/`. 평가·그림·PLY: `results/planar_residual_depth/P3e-kitti-000007-20261117-001/`.

K04 결과 해석: B2는 B0 대비 ROI MAE를 91.01%, B3는 79.49% 줄였다. B3의 보류 대응 오차는 B2보다 작지만 깊이 MAE는 15.99cm 크고 방향 오차도 증가했다. 이미지 간 대응 오차 최소화가 GT 방향·깊이 정확도와 일치하지 않는 사례다. 원인을 확정하거나 새로운 파라미터를 선택하지 않았다.

고정 평가 ID 000005–000007의 세 도로 영역에서 모두 B2 MAE가 가장 작았다. 도로 외 실내·다른 방향 평면이나 장시간 SLAM에 대한 검증은 남아 있다.
