# P31 실험 계획 — 영상 전역 평면·메시 기반 VGGT-Ω pointmap 정제

## 1. 목표

영상 전체에서 평면 또는 연결된 평면 조각으로 설명할 수 있는 표면을 찾는다. 검증을 통과한 영역은 confidence가 높은 픽셀까지 투영해 요철을 줄이고, 벽의 평탄성, 지붕의 용마루, 도로의 높이와 경사 변화를 보존한다. 정제된 pointmap과 표면 메시를 함께 내보내 후속 재구성에서 재사용할 수 있는 구현을 목표로 한다.

P26에서 채택한 `edge_3x3_3pct`를 경계 처리의 기준으로 사용한다. P29에서는 RGB 선으로 벽 법선이 개선됐으나 공통 평가 픽셀의 깊이 MAE는 20.65 → 25.80 cm로 증가했다. 따라서 다중시점 지지는 평면 방향과 위치를 각각 검사한다. P30 원통 보정도 보류 LiDAR에서 개선을 확인하지 못했으므로 SAM으로 식별한 인스턴스에만 별도 검증을 적용한다. [P26–P30 실험 기록](experiments/planar_residual_depth/index.md#p29-벽-방향-추정의-적용-조건)

## 2. 입력과 검증 분할

- VGGT-Ω 체크포인트, 코드 revision, 공동 추론 프레임, RGB 전처리와 좌표 변환, 원본 depth·confidence·K·pose를 기록한다. 비교군은 같은 추론 결과와 카메라, 스케일을 사용한다.
- 경계 마스크는 원본 깊이의 3×3 상대 범위 3% 기준으로 한 번 생성한다. 보정 후에도 마스크를 고정하고 전체 제거율과 영역별 투영률을 별도로 보고한다.
- FIT 프레임과 트랙으로 영역 연결 및 형상 추정을 수행한다. PILOT에서 검증 기준을 정한 뒤 EVAL 장면과 평가 마스크를 고정한다. 한 트랙의 관측을 피팅과 보류 양쪽에 넣지 않는다.
- 같은 VGGT-Ω 공동 추론에 포함됐지만 형상 피팅에서 제외한 프레임은 **피팅 보류**로 표시한다. 독립 검증은 파일럿에 사용하지 않은 클립에 고정된 절차를 적용한다.
- 센서 참조는 사후 평가에 사용한다. 스케일 정렬에 센서가 필요한 경우 별도 정렬 표본만 사용하고, 모든 비교군에 같은 스케일을 적용한 뒤 그 표본을 평가에서 뺀다.

## 3. 영역 검출과 형상 추정

1. **영상 전역에서 후보를 생성한다.** 경계 필터를 통과한 점에서 국소 법선과 깊이로 정규화한 평면 잔차를 계산한다. 고신뢰 점을 초기 지지로 사용하고, 연결 영역에서 방향·위치가 일치하는 후보를 확장한다. 벽·바닥·도로 같은 시맨틱 클래스 목록으로 탐색 범위를 제한하지 않는다. RGB 경계와 SAM 마스크를 후보 분리 및 가림 확인에 사용한다.
2. **시점 간 같은 표면을 연결한다.** 카메라 기하로 양방향 재투영하고, 겹침·가시성·공간 분포를 확인한다. RGB 패턴이나 선 대응이 지지하는 경우 다중시점 평면 방향을 추정한다. 평면 위치는 고신뢰 깊이 지지와 시점 간 일관성으로 별도 확인한다. 반대편 벽이나 가려진 영역은 깊이 순서와 재투영으로 구분한다.
3. **표면별 자유도를 정한다.** 같은 평면으로 충분한 영역은 하나의 평면으로 유지한다. 실제 접합선이나 경사 변화가 여러 관측에서 확인되면 면을 추가한다. 후보 분할이 피팅 오차를 줄여도 보류 관측에서 지지가 부족하면 더 단순한 형상을 유지하거나 투영을 보류한다.

| 대상 | 형상 추정 | 연결 제약 |
|---|---|---|
| 벽과 평평한 표면 | 유한 평면 다각형을 맞추고 윤곽에 따라 삼각분할한다. 사각형 벽은 삼각형 두 개로 표현한다. | 같은 다각형의 삼각형은 평면을 공유한다. 창문 등 별도 표면으로 확인된 구멍과 분리된 관측 영역을 보존한다. |
| 드론 영상의 지붕 | RGB 윤곽과 여러 시점에서 대응되는 용마루·사선 모서리로 지붕 면을 나눈다. 각 면은 따로 평면을 맞추고 필요하면 삼각분할한다. | 용마루는 인접 면의 공유 변으로 피팅한다. 깊이는 연결되고 법선은 꺾일 수 있다. 한 평면 내부의 삼각분할 대각선은 같은 법선을 갖는다. |
| 굴곡 도로 | 도로 영역 안에서 공유 꼭짓점 높이를 함께 최적화한다. 종단·횡단 경사 변화가 있는 부분에서만 메시를 세분화한다. | 공유 변에 틈과 높이 단차가 없어야 한다. 내부 기울기에는 완만한 변화 제약을 두고 연석과 확인된 높이 단절은 영역 경계로 둔다. |
| 원통형 물체 | 여러 시점에서 연결된 SAM 인스턴스에 P30 계열 원통 후보를 적용한다. | 반복 관측과 보류 결과가 형상을 지지할 때만 갱신한다. 근거가 부족한 곡면과 혼합 영역은 원본을 유지한다. |

## 4. 투영과 출력

카메라 픽셀의 광선을 해당 유한 다각형 또는 삼각형과 교차시켜 깊이를 계산한다. 양의 교점이 관측된 면 내부에 있고, 가림과 다른 면의 소속 충돌이 없으며, 깊이 변위가 파일럿에서 고정한 범위에 들어오는 점을 갱신한다. 경계 소속이 모호한 점이나 조건을 통과하지 못한 점은 원본 깊이를 유지한다. 한 번 갱신한 depth·XYZ는 같은 광선과 좌표계를 사용해 일관되게 생성한다.

- 원본과 동일한 픽셀 격자의 depth·XYZ pointmap, confidence, 고정 경계 마스크, 적용 마스크, 깊이 잔차를 저장한다.
- 평면 ID·계수·다각형 윤곽·구멍, 삼각형 인덱스·공유 꼭짓점·인접 관계, 접합선 유형을 저장한다.
- 각 픽셀의 `(frame_id, pixel_uv)`에 표면 ID와 적용 또는 보류 사유를 연결한다. 평면별 피팅·보류 관측 ID, 분할·병합 이력을 보존한다.
- 원본·경계 필터 기준선·정제 결과를 RGB PLY로 내보낸다. 비교용 PLY는 수정된 점을 오렌지 RGB (255, 145, 20)로 표시한다. 프레임별 깊이 잔차와 표면 ID 오버레이도 저장한다.

## 5. 단계와 비교군

| 단계 | 실험 | 비교 |
|---|---|---|
| P31a | P26–P29와 같은 TUM 16장에서 전역 검출과 벽·바닥 투영을 구현한다. 수동 확인 영역은 후보 품질 감사에 사용한다. | 원본 경계 필터 기준선, 같은 평면에서 저신뢰 점만 투영, confidence 전 구간 투영 |
| P31b | 용마루가 여러 영상에서 보이는 드론 지붕 클립을 선정한다. 우선 수동 RGB 선으로 형상 모델을 검증한 뒤 자동 검출을 별도 비교한다. | 기준선, 지붕 단일 평면, 공유 접합선을 갖는 다중 평면 |
| P31c | 오르막·내리막과 경사 전환이 보이는 도로 클립을 선정한다. | 기준선, 도로 단일 평면, 공유 꼭짓점 삼각형 메시 |
| P31d | 별도 클립에서 전역 처리와 내보내기를 반복한다. SAM 원통 보정은 평면·메시 결과에서 분리해 소규모 비교를 수행한다. | 경계 필터 기준선, 검증된 평면·메시, 검증된 원통까지 적용한 결과 |

드론과 굴곡 도로의 데이터는 프레임 목록, 시차, 보류 시점, 참조 깊이 유무를 확인한 뒤 고정한다. P31a는 기존 클립 재사용에 따른 파일럿으로 기록한다.

## 6. 평가와 완료 기준

- **공통** — 동일 센서 유효 픽셀에서 MAE·RMSE·절대오차 p90을 보고한다. 전체 유효 픽셀과 공통 보정 후보를 각각 집계하고, 낮은 confidence와 높은 confidence의 결과를 나눈다. 평면 잔차, 후보 대비 적용률, 적용 거부 사유와 프레임별 악화도 함께 기록한다.
- **벽** — 센서 참조가 충분한 영역에서 법선 각도와 평면 위치 오차를 따로 측정한다.
- **지붕** — 피팅 보류 영상에서 용마루와 외곽선의 재투영 오차, 면 내부 평탄성, 공유 변의 깊이 연속성을 측정한다.
- **도로** — 종단·횡단 프로파일에서 요철과 경사 변화의 보존을 비교한다. 센서 참조가 있으면 같은 구간의 높이·경사 오차를 측정한다.
- **참조가 없는 장면** — 보류 RGB 재투영과 시각 비교의 결과를 기록한다. 깊이 정확도 개선 결론은 센서 참조가 있는 평가에 한정한다.

파일럿에서 최소 지지 면적, 재투영 허용 오차, 방향·위치 안정성, 최대 변위 및 고신뢰 오차 허용치를 수치로 확정하고 독립 평가 전에 고정한다. 전역 처리와 재실행, pointmap과 메시의 소속 일치, 경계·공유 변 검사를 통과하면 구현 완료로 기록한다. 기본 활성화 여부는 보류 센서 깊이의 고신뢰 오차와 각 형상별 지표를 기준으로 별도 결정한다.

구현은 `experiments/planar_residual_depth/P31/` 아래에 두고, 실행별 결과는 `results/planar_residual_depth/P31a-<scene>-<date>-<NNN>/` 형태로 구분한다. 다른 단계는 같은 형식에 단계 ID를 바꿔 사용한다. 설정·입력 목록·실행 환경·로그·평가를 함께 저장하고 실패한 실행도 보존한다. GPU 실행은 샌드박스 밖에서 수행하고 GPU·CUDA·모델 환경을 실행 기록에 남긴다.
